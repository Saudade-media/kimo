# Getting help with Kimo

- **Docs first.** The [user guide](https://getkimo.design/docs/) covers installing, the editor,
  components, the built-in agent and export. The same pages live in this repository under
  [docs/guide](docs/guide/getting-started/install.md); coding agents have their own
  [agent guides](docs/agents/index.md), and the file format is specified in
  [docs/spec](docs/spec/kimo-format-1.0.md).
- **Questions, ideas and show-and-tell** go to
  [GitHub Discussions](https://github.com/Saudade-media/kimo/discussions). Search there first;
  someone may have asked already.
- **Bugs and feature requests** are [issues](https://github.com/Saudade-media/kimo/issues/new/choose).
  A bug report with steps to reproduce and, where possible, a minimal `.kimo` file gets fixed
  fastest.
- **Security vulnerabilities** are reported privately, never in an issue or a discussion. See
  [SECURITY.md](SECURITY.md).

Kimo is maintained by a small team, with no paid support. Answers come when someone has time,
and the [contributing guide](CONTRIBUTING.md) explains how to send a fix yourself.
