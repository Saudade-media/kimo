# Notes and prompts

Notes and prompts live on the canvas next to the design, are saved in the `.kimo` file, and are never part of the design: the Code tab and exports skip them.

## Notes

Press `N` for a sticky note in the middle of the view and start typing. A note records its author (your user name). Use notes for comments, decisions and to-dos. When a prompt runs, the notes on its target are passed to the agent with their authors.

Right-click a note and choose **Convert to prompt** to turn it into a prompt that keeps its text and position (several notes can be converted at once).

## Prompts

Press `⇧P` for a prompt and type an instruction for the [built-in agent](../built-in-agent/providers.md). A prompt can also name a model and a **target** frame.

- **Run** in the prompt's footer, the play button on its layer row, or **Run prompt** in the context menu sends it to the agent.
- **Set as target** (context menu) lets you click the frame the prompt should work on; the menu shows the current target.

What a run does is described in [Prompts and placeholders](../built-in-agent/prompts-and-placeholders.md).
